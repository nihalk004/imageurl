FREE GITHUB PAGES DEPLOYMENT

Host & Release SilverHalide on GitHub

STEP 1 • EXPORT CLEAN APP FILE

Download the standalone index.html file (without any cached personal tokens).

STEP 2 • PUSH TO GITHUB REPOSITORY

Create a public GitHub repo (e.g. silverhalide-app), upload index.html via the GitHub web UI (Add file → Upload files) or run:

git init
git add index.html
git commit -m "Release SilverHalide v1.0.0"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/silverhalide-images.git
git push -u origin main
STEP 3 • ENABLE GITHUB PAGES & TAG RELEASE

1. Open your repo on GitHub → Settings → Pages → under Build and deployment, select Deploy from a branch → choose main / / (root) and click Save.
2. Your live site will publish at: https://YOUR_USERNAME.github.io/silverhalide-images/
3. Optional: Go to Releases → Draft a new release, tag v1.0.0, and publish!
